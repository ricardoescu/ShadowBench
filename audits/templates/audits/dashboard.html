Adding clearly irrelevant semantic context repeatedly reduced an urgent benefits case from priority 3 to priority 2. Light spelling noise left the original priority unchanged.

This is a targeted adversarial investigation, not an estimate of the model's general failure rate. ShadowBench deliberately reallocates queries toward perturbation families that have already exposed instability.
